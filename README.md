# Concord MCP test: portfolio page built by an agent

A small experiment to try [Concord MCP](https://github.com/Get-Concord-AI/concord-mcp), an open-source, local-first MCP server that lets coding agents coordinate through shared work-state (presence, claims, task memory and handoffs).

## What I did

- Installed Concord MCP and set up a workspace (`test-concord`).
- Connected `gemini-cli` (`gemini-3.5-flash-lite`) to the Concord MCP server.
- Followed the agent's state in real time with `concord dashboard`.

## How the test went

1. **TASK-1:** registered `gemini-cli-agent` and checked session presence and workspace state initialization.
2. **TASK-2 ("Maquetar index.html del portfolio"):** the agent claimed the `index.html` scope with `claim_work`, built a responsive portfolio layout, and recorded the final state with `finish_work` and a `handoff` outcome.

The dashboard timeline shows the full flow: `claim_work` -> `close_task` -> `handoff`.
